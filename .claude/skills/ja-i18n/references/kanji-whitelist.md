## 需注意的邊界案例

### 取消 vs キャンセル

- **取り消し**（操作の取り消し）→ 「撤銷操作」語意，用於 undo 場景
- **キャンセル**（カタカナ） → Dialog 的「取消」按鈕，Goodpatch 設計慣例建議用カタカナ
- 兩者都是正確日文，但語意不同。Futari 的 Dialog cancel button 確認用哪個後記錄在此。

### 精算 vs 清算

- **精算**（せいさん）→ 費用結算、割り勘精算 ✅ Futari 正確用法
- **清算**（せいさん）→ 公司廢業、債務清算 ❌ 家計簿情境錯用

### 娯楽 vs エンタメ

- 兩者都見於實際 App，娯楽略正式，エンタメ較口語。Futari 選擇使用漢字「娯楽」→ 白名單保留。

### 相手 vs パートナー

指「另一半／要邀請的那個人」時，日本家計簿 App 有兩種寫法：

- **パートナー**（カタカナ）→ OsidOri 的 UI 用語（「パートナーを招待」）。夫婦／情侶類 App 的業界慣用詞。
- **相手**（漢字）→ 一般日文的「對方」，語意中性、不預設關係型態。

**Futari 選擇「相手」**，且既有文案已一致採用（`soloBanner.sendInviteHint: 'リンクを相手に送りましょう'`、
`setup.invite.qrHint: '相手がそばにいるなら…'`）。兩者都是正確日文，**不要因為看到 OsidOri 用
パートナー 就改掉**——那是它的品牌選擇，不是正確性問題。

附帶理由：CLAUDE.md 的 Solo 模式寫作規則要求不預設對方的關係與性別，「相手」比「パートナー」
更中性（後者隱含伴侶關係，但 Futari 也可能是室友或家人共用）。

## 更新指引

新增詞彙時，請：

1. 確認該詞在日本家計簿 App 實際 UI 或財務文章中以漢字書寫（搜尋「夫婦 家計簿 [詞彙]」「家計管理 [詞彙]」等）
2. 填入漢字、読み、用途說明、確認來源
3. 若有邊界案例（同音異義、漢字/假名並存），加入「需注意的邊界案例」區段
4. 更新文件頂部的「最後更新」日期
